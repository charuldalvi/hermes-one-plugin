# Moved: the Hermes One plugin now lives in [charuldalvi/hermes-one](https://github.com/charuldalvi/hermes-one), in its `plugin/` folder.

Install it (with the app, or on its own) from there:

```bash
curl -fsSL https://raw.githubusercontent.com/charuldalvi/hermes-one/main/install.sh | sh
```

or, plugin only:

```bash
hermes plugins install charuldalvi/hermes-one#plugin --enable
```

This repo is archived and won't get updates.
